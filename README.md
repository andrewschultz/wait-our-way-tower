# Wait-Our-Way Tower

Prospective IFComp entry for 2026

Big picture
* Written in Adventuron
* Uses similar engine to Go-Strange-Ghost Range, Chez Dark Shade Arc, Dusk Airy Does Carry (2025 EctoComp entries) with many code lines copied to/from
* Uses similar mechanics to Us Too and Why Pout, my 2025 and 2024 IFComp games.

Features
* 30 rooms, 5x5 structure with endgame
* 4 NPCs that follow, 3 friendly, 1 hostile
* THINK framework to remember
  * commands that still need in-game prep
  * halfway-solved commands
* In-game graphic map (on acquiring trivial bonus point)
